# Aiuto Truffe

Aiuto Truffe è un progetto pensato per aiutare persone anziane o con basse competenze digitali a riconoscere possibili truffe online.

L'idea principale è permettere all'utente di chiedere aiuto nel modo più semplice possibile, ad esempio inviando un messaggio vocale, una foto o uno screenshot tramite WhatsApp.

Il sistema analizza il contenuto ricevuto e restituisce una risposta chiara, indicando se il messaggio sembra sicuro, sospetto o pericoloso.

## Obiettivo

L'obiettivo del progetto è ridurre il rischio che una persona clicchi su link sospetti, inserisca dati personali o effettui pagamenti a causa di messaggi falsi.

Il servizio non sostituisce banche, forze dell'ordine o familiari, ma aiuta l'utente a fermarsi prima di compiere un'azione rischiosa.

## Struttura del progetto

- `frontend`: contiene la pagina web usata per testare il prototipo.
- `backend`: contiene la logica del sistema e i servizi principali.
- `database`: contiene i dati salvati dal sistema.
- `docs`: contiene la documentazione del progetto.

## Funzioni previste

- Analisi di messaggi sospetti.
- Riconoscimento del rischio: basso, medio o alto.
- Supporto a messaggi vocali.
- Supporto a immagini o screenshot tramite OCR.
- Possibile avviso a un familiare in caso di rischio alto.
- Collegamento futuro con WhatsApp.

## Stato del progetto

Il progetto è in fase iniziale. La prima versione sarà un prototipo semplice, utile per testare il funzionamento base prima di collegarlo realmente a WhatsApp.
